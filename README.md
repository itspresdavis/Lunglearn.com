# Lung Learn

The home of respiratory education. Learn anatomy. Understand disease. Master respiratory care.

This repository is the application: a public career guide, an adult male thoracic atlas, a draft academy, calculators, original practice questions, and accounts. Clinical lessons are visible as drafts and are not described as reviewed. Counts on the home page come from the content files.

## Scripts

```bash
npm install
npm test
npm run lint
npm run build
npm run dev
```

`npm run anatomy` rebuilds the thoracic GLB. It needs the BodyParts3D archive on the machine that runs it. The GLB already in `public/anatomy` is the file the site serves.

## Read first

`IMPLEMENTATION_STATUS.md` is the list of what works, what is missing, and which credentials are still required. `CONTENT_ACCURACY_POLICY.md` is the rule for what may be called published.

## Not included

No Stripe account, Supabase project, or Vercel project is attached to this repository. Checkout says so until the environment variables in `.env.example` are set. No anatomical mesh here was generated by an image model.

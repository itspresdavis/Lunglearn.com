# Roadmap

The order matches the product plan. Items already in the repository are not repeated as if they were still unstarted. See `IMPLEMENTATION_STATUS.md` for the honest inventory.

## Foundation, remaining

Connect Postgres using `db/migrations/001_initial.sql` with row-level security before any browser client is given a database key. Create the Stripe prices and the webhook. Set production secrets. Submit the site to Google Search Console after the canonical host is live.

## Anatomy

License and import a female dataset as separate meshes, not a recolor. Add lung parenchyma, pleura, and a true carina only from a source that already contains them. Add magnified alveolar models as a separate scale, with a caption that they are microscopic. Keep the layer checkboxes honest when a layer is still empty.

## Academy and reference

Expand lessons, diseases, and drugs under the editorial states. Add doses only with a cited label and a reviewer. Do not backfill epidemiology with round numbers.

## Board preparation and simulation

Write original items against the public NBRC outline until a 185-item form exists, then have it reviewed. Do not copy the outline’s wording into items. Add waveform, ventilator, and neonatal cases as more authored simulations, each with its assumptions on the page.

## Institutions

The classroom and inquiry tools are the start. A real institutional license needs a contract, a seat count, and a privacy review for education records. Grade export should wait until that review exists.

## Release checks still open

Content-security policy. Screen-reader pass. Measured frame time on a laptop and a phone. Dependency review on the lockfile. A backup story for `DATA_DIR` until Postgres is the store.
